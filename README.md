# Carefree Caravaneers — Forward Rally Viewer Handover

## Purpose

This document explains the Carefree Caravaneers Forward Rally Viewer and its management arrangements.

It is intended to assist the next Rally Coordinator taking over in July 2027.

## 1. Forward Rally Viewer

**Website:** https://rallyprogram.github.io/rally-viewer/

**GitHub repository:** https://github.com/RallyProgram/rally-viewer

The Forward Rally Viewer provides club members with access to the published rally program and related information.

It is separate from the Member Rally Nomination Portal, which handles members' YES, NO and MAYBE nominations.

**Important:** The existing Forward Rally Viewer website address should remain unchanged during the handover.

## 2. Website Hosting

The Forward Rally Viewer is hosted using GitHub Pages.

Current publishing settings:

- Repository owner: RallyProgram
- Branch: main
- Folder: / (root)
- HTTPS: Enabled
- Custom domain: None

The repository currently contains:

- index.html
- CaravanClubRallyManager.html

Changes to the published website should be tested before being released to members.

## 3. GitHub Access

The incoming Rally Coordinator will need appropriate access to maintain the Forward Rally Viewer.

Before July 2027:

- Confirm who will maintain the viewer.
- Arrange appropriate GitHub access.
- Ensure the incoming coordinator understands how website updates are published.
- Test the update procedure before transferring responsibility.

Do not share personal GitHub passwords or authentication recovery codes.

## 4. Relationship to Other Rally Systems

The club also operates:

**Member Rally Nomination Portal:** https://rallyprogram.github.io/carefree-member-portal/

**Club Website:** https://rallyprogram.github.io/carefree-caravaneers-website/

**Rally Manager Database:** Hosted using Supabase.

The incoming coordinator should understand how information is prepared, updated and published across these systems.

The exact update and data-refresh procedures should be documented and tested before handover.

## 5. Coordinator Handover Checklist

Before transferring responsibility:

- [ ] Confirm the incoming coordinator has access to the club's rally coordinator email.
- [ ] Arrange appropriate GitHub access.
- [ ] Confirm the Forward Rally Viewer opens correctly on a computer.
- [ ] Confirm it opens correctly on an iPhone.
- [ ] Confirm it opens correctly on an Android phone.
- [ ] Test how updated rally information appears in the viewer.
- [ ] Confirm the refresh procedure works correctly.
- [ ] Confirm the published website address remains unchanged.
- [ ] Confirm backup and recovery procedures.
- [ ] Document the process for publishing future updates.
